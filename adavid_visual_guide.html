Statistical Tests & Corrections

Welch's t-test (Global)

stats.ttest_ind(treatment, control, equal_var=False)
Tests if Treatment and Control groups differ significantly. Doesn't assume equal variances—more robust for real data.
t = (m₁ - m₂) / √(s₁²/n₁ + s₂²/n₂)

Bonferroni Correction

α_adjusted = 0.05 / number_of_segments
Prevents multiple comparison bias. If testing 20 segments at α=0.05, false positive rate = 64%. This reduces it to ~2.5%.
FWER = 1 - (1 - α)^k ≈ k·α (for small α)

Sample Size Validation

if len(ctrl) < 5 or len(treat) < 5: continue
Minimum n=5 per group per segment prevents statistical noise from underpowered tests.
Statistical power ∝ √n (larger n = more reliable)

Simpson's Paradox Test

if global_trend and not segment_trend: paradox_detected = True
Detects when drug works overall but fails in specific subgroups—critical regulatory red flag.
Paradox = Global(Treated > Control) AND Segment(Treated ≤ Control)
Patient Segmentation Matrix

The engine segments patients into 3D clusters: Age_Group × Genetic_Variant_X × Comorbidities_Count

Dimension Categories Count Purpose
Age_Group Young (≤35) | Middle-Aged (36-60) | Senior (>60) | Unknown 4 Age-dependent drug metabolism varies
Genetic_Variant_X True (carrier) | False (non-carrier) 2 Pharmacogenetic response predictor
Comorbidities_Count 0, 1, 2, 3, 4 chronic conditions 5 Drug-disease interaction risk
Maximum Possible Segments 4 × 2 × 5 = 40 clusters

Why Multidimensional Segmentation?

Real patients are complex. A drug might work great for young genetic carriers with no comorbidities but fail for elderly non-carriers with multiple conditions. Testing only the aggregate effect would miss these critical patient safety issues.

Key Regulatory Concepts

🎯 Simpson's Paradox in Pharma

A drug shows +25% improvement overall but fails in young patients (-5%) and helps elderly patients (+60%). The overall success masks a critical safety issue: the drug is contraindicated for youth.

Global: (60% of patients improve) | Youth: (20% improve) | Elderly: (85% improve)

⚠️ Regulatory red flag: Requires stratified approval or additional studies

📊 Bonferroni Correction Explained

If you flip a coin 20 times and declare "heads is more likely" whenever you see 6+ heads in a row, you'll make false claims ~64% of the time. Bonferroni reduces your threshold to account for this.

Standard: α = 0.05 → 5% false positive per test
Multiple (20 tests): α = 0.0025 → ~0.25% false positive per test

🔍 Data Validation Safeguards

Before any statistical test, the code removes:

  • Null values in critical fields (Patient_ID, Group, Outcome)
  • Invalid categorical values ("INVALID_ENTRY" groups)
  • Impossible biological values (negative age)
  • Underpowered segments (<5 samples per group)

Report Interpretation Guide

✅ GREEN LIGHT: Full Approval

Global p < 0.05: Drug is effective ✓
Simpson's Paradox: NOT detected ✓
All segments: Positive trend ✓

→ APPROVE FOR GENERAL USE

⚠️ YELLOW FLAG: Conditional Approval

Global p < 0.05: Drug shows efficacy ✓
Simpson's Paradox: DETECTED ⚠️
Some segments: Fail or show harm

→ CONDITIONAL APPROVAL with restrictions

  • Pharmacogenetic testing required
  • Age-adjusted dosing
  • Contraindicated in non-responder groups
  • Mandatory post-market surveillance

🚨 RED FLAG: Rejection

Global p ≥ 0.05: NO efficacy demonstrated
→ REJECT - Insufficient efficacy

Note: Even if some subgroups show benefit, failure at population level = regulatory rejection
