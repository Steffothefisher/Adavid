## 💡 **PRO TIPPS**

### **Tipp 1: SSH Key Setup (Optional)**

```bash
# In Termux:
pkg install openssh
ssh-keygen -t rsa -b 4096

# Copy public key:
cat ~/.ssh/id_rsa.pub

# GitHub: Settings → SSH Keys → Add Key
# Paste den Key
```

### **Tipp 2: Externe Keyboard**

Wenn du ein Bluetooth Keyboard hast:
```
→ Termux wird viel schneller
→ Vollständiges Coding vom Tablet möglich
→ Workflow wie auf Laptop
```

### **Tipp 3: Auto-Push Script**

```bash
# Erstelle in Termux: auto_push.sh
nano auto_push.sh

# Paste:
#!/bin/bash
cd ~/adavid-pharmaceutical-audit
git add .
git commit -m "Auto-commit from Android $(date)"
git push origin main
echo "✅ Pushed to GitHub!"

# Speichern: Ctrl+X → Y → Enter

# Executable machen:
chmod +x auto_push.sh

# Ausführen:
bash auto_push.sh
```

## ⚠️ **HÄUFIGE FEHLER & LÖSUNGEN**

### **Fehler: "git: command not found"**

**Lösung:**
```bash
# In Termux:
pkg install git
# Dann nochmal versuchen
```

---

### **Fehler: "Permission denied" beim Push**

**Lösung 1: SSH Key nutzen**
```bash
# In Termux:
ssh-keygen -t rsa
cat ~/.ssh/id_rsa.pub

# GitHub Settings → SSH Keys → Add Key
# Paste public key
```

**Lösung 2: Personal Access Token**
```
1. GitHub: Settings → Developer Settings
2. Personal Access Tokens → Tokens (classic)
3. Generate New Token
4. Select: repo (full control)
5. Copy Token
6. Verwende Token statt Passwort beim Push:
   git push origin main
   Username: YOUR_USERNAME
   Password: PASTE_TOKEN_HERE
```

---

### **Fehler: "Repository not found"**

**Lösung:**
```
1. Check GitHub URL:
   https://github.com/YOUR_USERNAME/REPO_NAME.git

2. Repo muss PUBLIC sein (nicht private)

3. Check Spelling von USERNAME und REPO_NAME
```
