## ⚠️ HÄUFIGE PROBLEME & LÖSUNGEN

### **Problem 1: "Permission Denied" beim Push**

**Lösung:**
```
Option A: SSH Key verwenden
  → MGit Settings → SSH Keys
  → GitHub Settings → Add SSH Key

Option B: GitHub Personal Access Token
  → GitHub Settings → Developer Settings
  → Personal Access Tokens
  → Create Token (repo access)
  → Verwende Token statt Passwort
```

---

### **Problem 2: "Repository not found"**

**Lösung:**
```
1. Verifiziere GitHub URL:
   https://github.com/USERNAME/REPO_NAME.git

2. Stelle sicher dein Repo ist PUBLIC (nicht private)

3. Check Spelling: USERNAME und REPO_NAME
```

---

### **Problem 3: Große Dateien (>100MB)**

**Lösung:**
```
Nutze Git LFS mit AxGit:
  1. AxGit → Setze LFS auf
  2. Nutze: git lfs track "*.pdf"
  3. Large Files können dann gepusht werden
```

---

### **Problem 4: SSH Key Fehler**

**Lösung:**
```
1. Generiere neue SSH Key (im Terminal)
   ssh-keygen -t rsa -b 4096 -f ~/.ssh/github

2. Kopiere public key:
   cat ~/.ssh/github.pub

3. GitHub Settings → SSH Keys → Add Key

4. In MGit Settings → SSH Keys → Select Key
```
